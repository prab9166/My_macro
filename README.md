# Multi-File Excel Data Matching Automation

## Overview

This project automates the process of matching and consolidating data from multiple Excel files using VBA.

The macro reads several datasets, matches records using unique identifiers, and combines the results into a structured output file.

The automation was created to replace a manual data matching process that previously took about two hours.

---

## Problem

In many data workflows, analysts need to merge multiple Excel files and match records using ID fields.

Doing this manually can be slow and error-prone.

---

## Solution

This VBA macro automates the process by:

1. Loading multiple Excel datasets
2. Matching records using unique identifiers
3. Retrieving relevant fields
4. Consolidating everything into a single structured dataset

The automation reduced a **2-hour manual process to under 5 minutes**.

---

## Technologies Used

- Excel
- VBA
- Data Matching
  
---

## How to Use

1. Open the Excel workbook containing the VBA macro
2. Place the source files in the specified directory
3. Run the macro
4. The script will generate a consolidated output file
